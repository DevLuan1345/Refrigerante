## 🥤 Landing Page - Refrigerantes

## 📌 Descrição do Projeto

Este projeto consiste em uma landing page interativa de refrigerantes, desenvolvida com foco em design moderno e experiência do usuário.

A aplicação apresenta diferentes sabores (Morango, Abacate e Laranja) em um slider animado, onde cada item possui identidade visual própria, com cores e imagens personalizadas.

O objetivo do projeto é praticar conceitos de front-end, incluindo manipulação do DOM, animações em CSS e responsividade.

## 🚀 Funcionalidades

- 🔄 Slider interativo entre sabores
- 🎨 Mudança dinâmica de cores de fundo
- 🖼️ Imagens sobrepostas com efeito visual (blur + destaque)
- ⏩ Navegação com botões (anterior/próximo)
- 📱 Layout responsivo para dispositivos móveis
- ✨ Animações suaves ao trocar os itens

## 🛠️ Tecnologias Utilizadas

- HTML5 🟧
- CSS3 🟦
- JavaScript 🟨

## 🎯 Conceitos Aplicados

- Manipulação de classes com JavaScript
- Uso de querySelector e eventos (onclick)
- CSS com variáveis (--background)
- position: absolute para sobreposição de elementos
- Animações com @keyframes
- Media Queries para responsividade

## 📱 Responsividade

O projeto foi adaptado para diferentes tamanhos de tela:

- 💻 Desktop
- 📲 Tablet
- 📱 Smartphones

Garantindo boa visualização e usabilidade em todos os dispositivos.

## 🎨 Layout e Design

Cada slide possui:

- Uma cor temática
- Um título centralizado
- Uma imagem de fundo (fruit com blur)
- Uma imagem principal (lata de refrigerante)

Criando um visual moderno e dinâmico inspirado em interfaces profissionais.
